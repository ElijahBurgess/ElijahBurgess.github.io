Toddler Touch Screen Lock — Privacy Policy

Effective Date: October 31, 2026
App Name: Toddler Touch Screen Lock (com.burgessmeditation.touchguard)
Publisher / Developer: Burgess Meditation LLC

Toddler Touch Screen Lock, published and maintained by Burgess Meditation LLC, is an offline parental utility for Android that temporarily blocks accidental touchscreen input during infant, baby, and toddler video calls or audio playback while allowing an adult to unlock the screen via a physical Volume button sequence (Volume Down ×3 followed by Volume Up ×3) or by plugging in a USB charging cable.

1. Zero Data Collection or Network Transmission

  • Toddler Touch Screen Lock does not request Android's INTERNET permission.
  • The app never collects, stores externally, sells, or transmits any personal data, telemetry, or device identifiers to Burgess Meditation LLC or any third party.
  • The app embeds zero third-party analytics, crash-reporting, or advertising SDKs.

2. Android AccessibilityService API Disclosure

Toddler Touch Screen Lock uses the Android AccessibilityService API solely when explicitly enabled and triggered by an adult user on-device to:

  1. Display a temporary touch-blocking overlay (TYPE_ACCESSIBILITY_OVERLAY)—plus an optional on-demand floating start button or dimmed night screen veil—over the active screen.
  2. Detect physical Volume button presses (onKeyEvent) locally to match the hardware unlock combo.

Toddler Touch Screen Lock is a parental touchscreen-lock utility, not an assistive disability tool (android:isAccessibilityTool="false"). Window content inspection is permanently disabled (canRetrieveWindowContent="false") and gesture injection is disabled (canPerformGestures="false"). The app never reads screen text, notifications, passwords, or audio/video content.

3. Private On-Device Storage Only

User preferences (lock duration, countdown delay, shield display options, and Dark Mode) and a rolling local diagnostic log are stored exclusively on your device in the app's private internal sandbox and are automatically erased when the app is uninstalled.

4. Target Audience & Children's Privacy

Toddler Touch Screen Lock is a parental utility intended to be purchased, installed, configured, and operated exclusively by adults (ages 18+). Because the app operates 100% offline with zero data collection, Burgess Meditation LLC never collects personal information from adults or children.

5. Contact

For questions regarding this Privacy Policy, please contact Burgess Meditation LLC via the developer contact email published on the Google Play Store listing for Toddler Touch Screen Lock.
